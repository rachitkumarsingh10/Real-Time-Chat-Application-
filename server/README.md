# QuickChat — Server (Backend)

This is the server application for **QuickChat**, built with **Node.js**, **Express**, **Socket.io**, **Mongoose (MongoDB)**, and **Cloudinary**.

For complete documentation on setup, environment variables, APIs, and folder structure, please refer to the main repository documentation:

👉 **[QuickChat Root README.md](../README.md)**

## Quick Start

```bash
# Install dependencies
npm install

# Setup environment variables
cp .env.example .env

# Run development server with hot-reload
npm run server
```
